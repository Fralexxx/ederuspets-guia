# Guía de EderusPets

Guía pública de las mascotas de Ederus Network. El código del plugin permanece en el repositorio privado de EderusPets.

## Sitio

https://fralexxx.github.io/ederuspets-guia/

## Mascotas y habilidades

| Categoría | Mascota | Habilidad | Efecto |
| --- | --- | --- | --- |
| Minería | Topo | Fortuna de minería | Probabilidad de obtener drops adicionales al minar. |
| Minería | Armadillo | Velocidad de minado | Prisa al sostener un pico. |
| Minería | Murciélago | XP de minería | XP adicional al minar, tanto para la mascota como para el jugador. |
| Farming | Conejo | Fortuna de farming | Probabilidad de obtener cultivos adicionales. |
| Farming | Abeja | XP de farming | XP adicional al cosechar, tanto para la mascota como para el jugador. |
| Farming | Cerdo | Ahorro de semillas | Probabilidad de obtener semillas adicionales al cosechar. |
| Tala | Mono | Fortuna de tala | Probabilidad de obtener drops adicionales de troncos. |
| Tala | Oso | Velocidad de tala | Prisa al sostener un hacha. |
| Tala | Ardilla | XP de tala | XP adicional al talar, tanto para la mascota como para el jugador. |
| Pesca | Delfín | Fortuna de pesca | Probabilidad de obtener otra copia de la captura. |
| Nether | Blaze | Daño del Nether | Más daño a criaturas hostiles del Nether. |
| Nether | Esqueleto Wither | Resistencia del Nether | Menos daño recibido de criaturas hostiles del Nether. |
| Nether | Piglin | XP del Nether | Más experiencia al derrotar criaturas hostiles del Nether. |

Los valores exactos y las condiciones de cada habilidad aparecen en la [guía web](https://fralexxx.github.io/ederuspets-guia/). La fuente de esta lista es `pets.yml` y la implementación de habilidades de EderusPets 2.3.1.
